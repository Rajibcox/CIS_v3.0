# QUANTUM TRADER V1

Professional Quantitative Futures Trading & Intelligence Platform

## Overview

QUANTUM TRADER V1 is a comprehensive cryptocurrency futures trading platform designed for professional quantitative trading. It provides market intelligence, automated scanning, strategy execution, and advanced risk management for Binance and Bitget USDT-M perpetual futures.

## Features

- **Market Intelligence**: Real-time market scanning and analysis
- **Automated Trading**: Multiple independent trading strategies
- **Risk Management**: Dynamic leverage calculation and position sizing
- **Profit Protection**: Advanced TP/SL management with trailing stops
- **Paper Trading**: Realistic simulation environment
- **Backtesting**: Historical strategy validation
- **Telegram Integration**: Command center and notifications
- **Web Dashboard**: Professional trading interface
- **Portable Deployment**: Self-contained Windows application

## Quick Start

1. Run `INSTALL_QUANTUM_TRADER.bat` to set up the application
2. Run `START_QUANTUM_TRADER.bat` to launch the platform
3. Access the web dashboard at `http://localhost:8000`
4. Configure exchanges and strategies through the web interface

## Requirements

- Windows 11 64-bit
- N: drive with minimum 10GB free space
- Internet connection for exchange APIs
- Compatible web browser (Chrome, Firefox, Edge)
